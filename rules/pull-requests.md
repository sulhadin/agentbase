# Pull requests

- Title: `#<ClickUpTaskId> - <title>`. Take the id from the branch (`CU-xxxx` → `xxxx`); use `#0` when there is none.
- Description follows the repo's `.github/pull_request_template.md`: `## Changelog` bullets, then `## Description` (1–2 sentences). Add `## Before merge` only when something gates merging.
- Close with the ClickUp id on its own line. No AI attribution footers.
